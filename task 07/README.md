# Dank Meme Discord Bot

<p>This task was to build a discord bot,the code structure was already given along with the task,so i started with creating the folders
and adding python files just like in the structure and installed the necessary dependencies..There was a .env file in that ,in that i had to give the discord token,
.So i got that discord token from the developer's portal of disocrd,after creating an application in the bot tab.then i change some setting OAuth2 section and authorised the boat in my fake discord account 
first for testing then did the same for my real one.Then the token i got was pasted in the .env file.</p>

<p>After that I started filling the python files , i dont have much idea on coding so learning it from scratch was not possible in a day or two,so i got the code then learned from it
and replicated it.In the database file i imported the os and all,and using the aiosqlite,a python library to create a user table which conatins user id,username etc.
IT also updates the balances,other updates like last_rob and all.There should be a bot.py file but for my understanding i put it as main.py which holds the commands on which the bot acts on
and also has the different functions for each files like it loads the token from the .env file and starts up the database file etc.</p>

<p> Then in the cogs folder there are three files,fun.py which shows the fun responses to the user like the bounty,devil fruit info etc,the games.py file which plays rock paper scissors
when given the certain input and lastly economy.py which responses are related to the amount of berries for different commands.</p>

Overall after finishing it,it was pretty fun to play around with .I never knew before that these discord bots could be customized to do different things.I would like to try other things too
now that i have got an idea of how it works.
