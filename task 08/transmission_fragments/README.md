# Pixel Merger

<p>This task was to put together the fragments or pieces of an image to form the full image.In the task it was said that the transmission was split into hundreds of pieces but that was
too much of pieces for me to work with so i took an image from online and split it into 10 pieces ,10 rows and 1 column manner because the website i went to split it that way haha.</p>
<p> First imported all the necessary python libraries and used two functions ,first one to arrange the images in row wise till row 10 and the second one to retrieve the image which was 
input from the image files which has jpg format.Then a function for reassembling it to make the correct images and two print statements just to print some sentence and and if statement to
give what if there was no fragments.Then again a print statement to show a sentence to the user to show that the image was reconstructed and finally the reconstructed image
is added to the folder as a file named "secret_imperial_message.jpg"</p>
